CSS Aural Reference

Aural CSS was designed to control how documents are presented through speech synthesizers and screen readers.

Property Description
volume Controls the volume of the spoken content.
voice-family Specifies the voice family.
speak Specifies whether content should be spoken.
pause-before Specifies a pause before an element is spoken.
pause-after Specifies a pause after an element is spoken.
cue-before Specifies a sound before an element.
cue-after Specifies a sound after an element.
Note: Modern web accessibility generally relies more heavily on semantic HTML and dedicated accessibility technologies than on legacy aural CSS properties.
