CSS Properties Reference

CSS properties are used to define how HTML elements should be displayed and styled on a webpage.

Property Description Example
color Sets the text color. color: blue;
background-color Sets the background color. background-color: yellow;
font-size Sets the size of text. font-size: 20px;
font-family Specifies the font. font-family: Arial;
margin Creates space outside an element. margin: 20px;
padding Creates space inside an element. padding: 15px;
border Creates a border around an element. border: 1px solid black;
width Sets the width of an element. width: 300px;
height Sets the height of an element. height: 200px;
display Controls how an element is displayed. display: flex;
Example:
p { color: blue; font-size: 18px; margin: 10px; }
