CSS Selectors Reference

CSS selectors are used to select HTML elements that need to be styled.

Selector Example Description
Element Selector p Selects all paragraph elements.
Class Selector .box Selects elements with class="box".
ID Selector #header Selects the element with id="header".
Universal Selector * Selects all elements.
Group Selector h1, h2, p Selects multiple elements.
Child Selector div > p Selects direct child paragraphs.
Descendant Selector div p Selects paragraphs inside div.
Attribute Selector input[type="text"] Selects text input elements.

Example

p { color: blue; } .box { background-color: yellow; } #header { font-size: 30px; }
