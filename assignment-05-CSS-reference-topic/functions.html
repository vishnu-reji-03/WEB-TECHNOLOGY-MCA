CSS Functions Reference

CSS functions perform calculations and generate values that can be used by CSS properties.

Function Example Purpose
rgb() rgb(255, 0, 0) Defines a color using RGB values.
rgba() rgba(255, 0, 0, 0.5) Defines a color with transparency.
calc() calc(100% - 50px) Performs mathematical calculations.
min() min(50%, 400px) Returns the smallest value.
max() max(20px, 5vw) Returns the largest value.
clamp() clamp(16px, 3vw, 30px) Sets a minimum, preferred and maximum value.
var() var(--main-color) Uses a CSS custom property.
url() url("image.jpg") Specifies a resource URL.

Example

.box { width: calc(100% - 40px); color: rgb(0, 100, 255); }
