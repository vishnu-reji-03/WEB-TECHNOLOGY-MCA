CSS Animatable Reference

Animatable CSS properties can change their values gradually during a CSS transition or animation.

Property Animatable Example
color Yes color: red;
background-color Yes background-color: blue;
width Yes width: 300px;
height Yes height: 300px;
opacity Yes opacity: 0.5;
transform Yes transform: rotate(45deg);
display No display: block;

Example

.box { transition: width 1s; } .box:hover { width: 300px; }
