CSS Default Values

HTML elements have default browser styles before custom CSS is applied.

Element Common Default Behavior
body display: block;
div display: block;
p display: block; with default margins
h1 Large bold heading with default margins
h2 Smaller heading with default margins
ul Block element with padding and bullets
a Inline element, usually underlined and colored
img Inline-level replaced element
button Inline-block form control with browser styling
