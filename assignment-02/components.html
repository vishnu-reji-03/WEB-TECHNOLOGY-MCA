2. Components of Web Application

View Layer

The View Layer is the presentation layer of a web application. It is responsible for displaying information to the user and providing an interface through which users can interact with the application.

It contains elements such as web pages, forms, buttons, menus, images, and other user interface components.

Examples: HTML, CSS, JavaScript, React, Angular.

Business Layer

The Business Layer contains the main logic and rules of a web application. It processes user requests, performs calculations, applies business rules, and determines how the application should respond to a particular request.

Examples: User authentication, order processing, price calculation, and data validation.

Data Access Layer

The Data Access Layer is responsible for communicating with databases and other data storage systems. It performs operations such as retrieving, inserting, updating, and deleting data.

Examples: SQL queries, Django ORM, database repositories, and database access APIs.
