5. Dynamic Web Pages

Definition

A dynamic web page is a web page whose content can change or be generated based on user input, data, time, or other conditions.

Unlike a static web page, where the content remains mostly unchanged, a dynamic web page can generate different content for different users or requests.

Examples: Online shopping websites, social media websites, banking websites, and web applications.

Characteristics

Dynamic web pages can provide personalized and interactive content to users. Their content can change according to user actions, database information, or other conditions.

Examples: User login pages, personalized dashboards, search results, and shopping carts.

Examples

E-commerce websites dynamically display products and prices, social media websites display personalized feeds, and banking websites show account information based on the logged-in user.

Examples: Amazon, YouTube, Facebook, online banking portals, and news websites.
