1. Client / Server

Client

A client is a device or software application that requests services or resources from a server over a network. In web technology, a web browser such as Google Chrome, Mozilla Firefox, or Microsoft Edge acts as a client. The client sends requests to the server and receives the requested data or services in response.

The client is usually responsible for providing the user interface through which users interact with a web application.

Examples: Web browser, mobile application, desktop application.

Server

A server is a computer or software system that receives requests from clients, processes them, and provides the requested resources or services.

A server can store and manage data, execute application logic, and deliver web pages or other resources to clients. In a web application, the server receives HTTP requests from clients, processes those requests, and sends an appropriate response.

Examples: Web server, database server, application server.
